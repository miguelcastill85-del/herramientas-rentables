## v2 superiority requirements

1. Pricing depth: sustainable rate + project economics + hidden time + fee-aware gross-up + walk-away / target / premium pricing.
2. Negotiation depth: client budget verdict, hours supported by budget, concession math and scope-for-price trade-offs.
3. Scope protection: explicit change-request pricing and free-scope erosion simulation.
4. Learning loop: quote-vs-actual, hidden-time leakage, effective rate, service-level pricing memory and historical calibration.
5. Benchmarking: traceable market benchmark library with source/date plus editable user evidence; avoid opaque static numbers.
6. Scenario analysis: at least three editable scenarios without VBA/macros.
7. Client output: clean client-facing offer/pricing summary separated from internal margins/floors.
8. Quality: no macros, no external paid dependency, transparent formulas, input validation, model health checks, worked example, guide and purchaser license.
9. Professional UX: clear PRICE -> PROTECT -> NEGOTIATE -> LEARN workflow, consistent input/output visual language and decision flags.
