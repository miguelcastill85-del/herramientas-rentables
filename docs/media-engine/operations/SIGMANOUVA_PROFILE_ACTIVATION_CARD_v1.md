## Para qué existe

Esta tarjeta evita tener que decidir otra vez cómo debe verse o qué debe decir cada cuenta. En cuanto confirmemos el usuario disponible, la configuración ya está preparada.

## Usuario que comprobamos primero

`@sigmanouva`

Si una plataforma no permite exactamente ese usuario, probar en este orden:

1. `@sigmanouva.media`
2. `@sigmanouva.lab`
3. `@sigmanouva.oficial`

No elegir una variante diferente solo por apuro. La idea es mantener el mismo nombre en las tres redes cuando sea posible.

## Enlace inicial

No necesitamos crear una web nueva antes de empezar.

Mientras sea relevante, podemos enlazar una herramienta o recurso útil de Herramientas Rentables. No se cambiarán productos, precios, fórmulas ni enlaces comerciales existentes solo por abrir SIGMANOUVA.

## Antes de publicar la primera pieza

Comprobar:

- mismo nombre de marca en las tres redes;
- usuario correctamente escrito;
- avatar correcto;
- bio/descripcion correcta;
- ningún logo antiguo de SIGMA;
- los tres posts fijados preparados;
- enlace funcional si se coloca uno;
- cuenta y contraseña protegidas con autenticación en dos pasos cuando la plataforma lo permita.

## Primera publicación

La primera publicación será supervisada. No activamos publicación automática total desde el primer día.

Después de publicarla comprobaremos que:

- la imagen correcta apareció;
- el texto no quedó cortado;
- no se duplicó;
- el enlace funciona si existe;
- podemos registrar correctamente las métricas.

Solo después de varias publicaciones correctas avanzamos hacia automatización.
