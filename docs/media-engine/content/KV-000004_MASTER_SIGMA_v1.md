## Core lesson

An initial number can become a reference point that influences later judgments. Anchoring does not mean the first number controls every decision, but it can systematically affect estimates and evaluations.

## Hook test

A: `El primer número que ves puede seguir influyendo aunque sepas que es solo una referencia.`

B: `¿Por qué el primer precio importa tanto? Porque puede convertirse en tu ancla.`

## Facebook adaptation

`El primer precio que vemos puede transformarse en una referencia mental para evaluar los siguientes.`

`Ese fenómeno se conoce como anclaje. Tversky y Kahneman mostraron que las personas pueden ajustar sus estimaciones desde un valor inicial y cometer errores sistemáticos por depender demasiado de ese punto de partida.`

`No significa que cualquier primer número controle automáticamente nuestra decisión. La intensidad depende del contexto.`

`Una forma práctica de reducir el efecto es definir antes tus propios criterios: cuánto vale para ti, qué alternativas existen y cuál es tu límite.`
