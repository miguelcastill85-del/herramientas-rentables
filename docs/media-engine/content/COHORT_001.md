# COHORT_001 — First 7-day editorial validation set

Status: PREP_IN_PROGRESS
Authority: MEDIA_ENGINE_WORKLOG_v1.1_GROWTH_PATCH

## Purpose

Validate whether Herramientas Rentables can convert practical, counterintuitive knowledge into discovery, saves, shares, profile visits and follows without relying on sales-heavy content.

This is not a revenue cohort. It is a discovery + conversion + learning cohort.

## Platform roles

- Instagram: daily discovery attempt.
- Facebook: redistribution/share attempts on the strongest broadly useful pieces.
- LinkedIn: 3 high-density authority posts from business/economic topics.

Do not force identical daily cadence on all three platforms.

## Guardrails

- Do not sell aggressively in this cohort.
- Do not route every post to Payhip.
- CTAs should primarily ask to save, share, compare, calculate or follow for the next useful idea.
- Every claim must match the verified Knowledge Vault item.
- Source detail must be retrievable from the repository even if social copy uses a short source label.

## Measurement windows

Record where available:

- 24h
- 72h
- 7d

Metrics:

- non-follower reach
- shares/reach
- saves/reach
- profile visits/reach
- follows/profile visits
- comments/reach
- watch retention for video
- clicks when used

## Fast-follow rule

If any item materially exceeds baseline on shares, saves or follow conversion, create a follow-up/content tree inside 72 hours rather than waiting for the monthly review.
