# Minimum Viable Formats v1

Status: SPEC_APPROVED

The goal is to launch with three repeatable formats, not a large template library.

## 1. Instagram Reel — discovery format

Working duration: approximately 20–45 seconds. The structure is more important than an exact duration.

### Required sequence

1. HOOK — first sentence must communicate a concrete tension, number, mistake or unexpected mechanism.
2. WHY IT MATTERS — one sentence connecting the mechanism to a real decision.
3. EXPLANATION — no more concepts than required.
4. EXAMPLE — use a real number or scenario whenever possible.
5. TAKEAWAY — one useful action or rule.
6. CTA — save/share/follow only when natural.
7. SOURCE — short source mention in caption; full record remains in Knowledge Vault.

### Prohibited

- intro logo before the hook
- generic greetings before value
- fake urgency
- unsupported certainty
- more than one main lesson per Reel

## 2. Instagram/Facebook Carousel — save format

Working range: 5–8 slides.

### Default 6-slide structure

1. Cover: one specific promise/tension.
2. The common mistake or setup.
3. The mechanism/formula.
4. Worked example.
5. What the viewer should do differently.
6. Brand close + save/share CTA + short source label.

### Visual rule

One idea per slide. Avoid dense paragraphs. Numbers that matter should be visually dominant.

## 3. Professional text post — LinkedIn authority format

Working length: enough to explain one idea cleanly without padding. Use roughly 150–350 words as an internal production range, not a platform law.

### Required sequence

1. Direct opening insight.
2. Concrete example or calculation.
3. Explanation of mechanism.
4. Limitation/caveat when material.
5. Practical implication.
6. Optional question that invites real professional discussion.

### Prohibited

- engagement bait
- fake personal stories
- generic AI-style lists without an argument
- copying the Instagram caption unchanged

## Facebook adaptation

Facebook may reuse the core research but should optimize for readability and sharing. Use a compact explanatory story, example, or Reel; do not treat it as a mirror of Instagram.

## Source handling

Every content file must point to a KV ID. The KV item is the claim authority. If social wording exceeds the KV claim, QA fails.
