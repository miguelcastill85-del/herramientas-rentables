# ZERO COST ECOSYSTEM POLICY v1

Status: ACTIVE_REQUIRED
Date: 2026-09-06
Project: SIGMANOUVA Media Engine

## Regla principal

SIGMANOUVA se construye con **costo adicional $0**.

No vamos a gastar dinero para crear, operar o escalar el ecosistema inicial de la marca, sus contenidos, productos digitales, servicios, redes sociales, automatizaciones o infraestructura de apoyo.

## Qué significa en la práctica

Mientras esta regla esté activa:

- no se compran dominios;
- no se paga publicidad;
- no se compran seguidores, visualizaciones o engagement;
- no se contratan agencias, freelancers o consultores;
- no se pagan herramientas de diseño;
- no se pagan APIs;
- no se pagan automatizadores;
- no se paga hosting nuevo;
- no se pagan bases de datos, servicios cloud o servidores;
- no se pagan bancos de imágenes, música o video;
- no se pagan herramientas de SEO;
- no se pagan herramientas de analítica;
- no se paga software adicional para publicar;
- no se paga registro de marca o asesoría legal durante la fase de construcción orgánica;
- no se activa ningún plan, crédito, prueba que pueda convertirse en cargo, ni recurso con costo sin una nueva decisión explícita del usuario.

## Qué sí podemos usar

Podemos usar recursos que ya estén disponibles sin costo adicional, por ejemplo:

- Instagram, Facebook y LinkedIn de forma orgánica;
- GitHub ya conectado;
- Dropbox ya conectado;
- las capacidades ya incluidas en la cuenta actual de ChatGPT;
- herramientas gratuitas y open source;
- planes gratuitos que no exijan pago ni creen cargos futuros automáticos;
- el sitio y activos existentes de Herramientas Rentables cuando ayuden y no generen un costo nuevo;
- plataformas de venta que no requieran pago por adelantado, siempre que cualquier comisión por una venta real se explique antes de depender de ella.

## Regla ante una opción pagada

Si una tarea normalmente se resuelve pagando:

1. primero buscar una alternativa gratuita;
2. si existe, usar la alternativa gratuita;
3. si no existe, rediseñar el proceso para evitar el costo;
4. si todavía no es posible, posponer esa parte;
5. esa limitación no debe detener el crecimiento orgánico salvo que sea realmente indispensable;
6. nunca realizar el gasto automáticamente.

## Dominio

Tener un dominio propio puede ser útil más adelante, pero **no es necesario para lanzar SIGMANOUVA en redes sociales**.

Por tanto:

- podemos investigar disponibilidad gratuitamente;
- no compraremos `sigmanouva.com`, `sigmanouva.cl` ni otro dominio durante esta fase;
- la falta de dominio no bloquea el lanzamiento ni la creación de audiencia.

## Marca y revisión legal

Podemos hacer búsquedas públicas y revisiones preliminares gratuitas para detectar conflictos evidentes.

No contrataremos una revisión legal ni pagaremos un registro de marca mientras la política de costo cero esté activa.

En consecuencia, nunca afirmaremos que SIGMANOUVA tiene exclusividad legal si no existe una verificación formal.

Esto tampoco debe impedir experimentar orgánicamente con la marca mientras se mantenga prudencia y no se realicen inversiones irreversibles.

## Productos y servicios

El objetivo final sí es generar ingresos mediante productos y servicios digitales.

La regla de costo cero significa que la **construcción del sistema** no requiere desembolso previo.

Preferimos modelos donde:

- crear el producto cueste $0 adicional;
- alojarlo o venderlo no exija mensualidad inicial;
- cualquier comisión ocurra solamente después de una venta real;
- se conserve la mayor flexibilidad posible para cambiar de plataforma.

Cualquier comisión, retención o costo ligado a una venta debe explicarse claramente antes de adoptar esa vía como sistema principal.

## Crecimiento

La primera etapa de crecimiento será orgánica:

- publicaciones útiles;
- formatos repetibles;
- distribución entre Instagram, Facebook y LinkedIn;
- contenido compartible y guardable;
- optimización basada en resultados reales;
- reutilización inteligente del contenido;
- colaboración gratuita cuando aporte valor;
- aprovechamiento de activos propios como Herramientas Rentables.

La falta de presupuesto no se considera un bloqueo metodológico. El sistema debe diseñarse desde el principio para funcionar sin publicidad pagada.

## Regla de control

Antes de cualquier acción que pueda crear un cargo, suscripción, renovación, compra o compromiso económico:

- detener esa acción;
- explicar en lenguaje simple qué cuesta y por qué;
- buscar primero una solución gratuita;
- no avanzar con el gasto mientras esta política siga activa.

## Continuidad entre chats

Esta política forma parte de la autoridad permanente del proyecto.

Todo chat, agente o flujo de trabajo que recupere SIGMANOUVA desde `docs/media-engine/HEAD.json` debe tratarla como obligatoria hasta que el usuario la cambie expresamente.
